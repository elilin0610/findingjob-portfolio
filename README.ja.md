# FindingJob Portfolio Demo

[繁體中文](./README.md) | [English](./README.en.md) | **日本語**

AI と協力して構築した求人調査ワークフローを、**安全に共有できるよう範囲を絞ったデモ**です。元の作業環境には非公開の履歴書やメールが含まれますが、このリポジトリには収録していません。元のシステムをすべて公開したものでもありません。

## 試せること

- 元のプロジェクトの JavaScript 製求人タイトルフィルターで、一次候補と、明らかにシニア職や管理職に当たる求人を区別できます。
- 架空の企業と求人を使い、重複排除・分類・確認待ちの扱いを確認できます。
- 元のプロジェクトの情報源の確認方法、履歴書の版管理、レビュー手順、ダッシュボード構成は、[事例紹介](CASE-STUDY.ja.md)をご覧ください。

デモはネットワーク通信やメール送信を行いません。実際の求職データを収録しておらず、API キーも不要です。

## クイックスタート

Node.js 20 以上を用意し、このディレクトリで次のコマンドを実行します。

```sh
npm run demo
npm test
```

サードパーティの依存パッケージはなく、`npm install` は不要です。出力は JSON です。Remote は情報源に記載された勤務地の表記であり、台湾から勤務できることを確認したものではありません。

## 使用技術とスキル

デモは Node.js、JavaScript ESM、JSON、node:test を使用しています。元のプロジェクトでは Python の PDF ツール、React/Vite のダッシュボード、独自の `taiwan-remote-job-search` スキルも使っていますが、**これらのモジュールは本リポジトリには含まれません**。サードパーティの Data App 共通フレームワークも複製していません。

## AI との役割分担

要件や希望条件の整理、作業工程の分解、実際に使ったうえでの改善提案は私が担当し、プログラムとドキュメントの作成を Codex が支援しました。すべてのコードを独力で手書きしたものではありません。このデモはポートフォリオの整理にあたり、元の設計を安全に紹介するために作成したもので、過去に稼働していたサービスではありません。

## 制限事項

ルールに基づく分類は一次選別であり、求人の受付状況、学歴要件の充足、ビザ取得の可否、仕事内容との適合性を保証しません。すべての例は架空で、求職活動の成果も保証しません。サービスはデプロイしておらず、自動応募も有効にしていません。
